# Darcula Theme from IntelliJ — Antigravity

Mirror of the `trinm1709.dracula-theme-from-intellij` VS Code theme, kept here for use with Google Antigravity IDE.

The theme provides an IntelliJ-style Darcula color scheme, including syntax-specific font styling.

## Installation

Build or download the `.vsix` package and install it in Antigravity:

```bash
antigravity-ide --install-extension darcula-theme-from-intellij.vsix
```

## Original extension

Original publisher: `trinm1709`

Extension ID:

```text
trinm1709.dracula-theme-from-intellij
```
